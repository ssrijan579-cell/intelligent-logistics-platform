# Intelligent Delivery Delay Prediction & Logistics Intelligence Platform

An enterprise-grade AI platform that predicts shipment delays, forecasts delivery ETAs, explains model predictions using Explainable AI, and provides actionable logistics intelligence through interactive dashboards and AI-powered recommendations.

## Features

- Shipment Delay Prediction
- ETA Forecasting
- Explainable AI (SHAP)
- Logistics Intelligence Dashboard
- FastAPI Backend
- React Frontend
- MLflow Experiment Tracking
- Docker Deployment
- AI Operations Copilot (Phase 2)

## Tech Stack

- Python
- FastAPI
- Scikit-learn
- XGBoost
- LightGBM
- SHAP
- PostgreSQL
- React
- Docker
- AWS
